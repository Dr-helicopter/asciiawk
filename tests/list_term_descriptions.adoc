
= AsciiAWK List Types: Full Regression Torture Test

This document tests description lists, checklists, callouts, nesting,
indentation, mixed list types, continuation, and termination.

The expected result is not always that every construct renders correctly.
Invalid cases are included to test false positives and recovery behavior.
